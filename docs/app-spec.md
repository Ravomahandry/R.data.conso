# App Specification (`app-spec.md`)

## 1. Executive Summary
**Arvo** is an advanced Android data management and consumption control application. It allows users to track their mobile and Wi-Fi data usage, set global and per-app daily/monthly quotas, simulate usage forecasts, block ads to reduce consumption, and strictly block internet access when quotas are reached.

## 2. Target Audience
- Conscious smartphone users who want active control over their data consumption.
- Individuals looking to optimize their time spent online and protect their financial portfolio from data overage charges.

## 3. Core Problem Solved
Eliminates unexpected data overages, prevents excessive time spent on bandwidth-heavy internet activities, and safeguards the user's financial portfolio through accurate quota enforcement and ad blocking.

## 4. Project Stage
- **Current Status:** V3 Restructuring. Core codebase exists with foundations in local database management, VPN/Accessibility blocking services, charts, and AI prediction. This version focuses on solidifying effective blocking mechanics and refining architecture.

## 5. Main Screens & Navigation
1. **Accueil (Dashboard):** Real-time consumption overview, quota status, quick actions, and simulation widgets.
2. **Historique (History):** Detailed logs of past consumption grouped by date, app, and connection type, with PDF/data export capabilities.
3. **Blocage (Blocking):** Configuration of global and per-app quotas, ad-blocking filters, and enforcement status.
4. **Paramètres (Settings):** User preferences, font selection (Maiandra GD + 4 alternatives), security guards, and ghost mode configurations.
