# Feature Backlog (`feature-backlog.md`)

## Version 1 Scope (V3 Baseline)
- [x] **Global & Per-App Quotas:** Input monthly/daily quotas for mobile and Wi-Fi.
- [x] **Effective Blocking Mechanism:** Enforce strict blocking of apps and global internet access when quotas are reached via VPN/Accessibility services.
- [x] **Consumption Simulation & Prediction:** Estimate usage trends and forecast exhaustion points.
- [x] **Dashboard:** Real-time data consumption overview and visual charts.
- [x] **Ad Blocking:** Filter ad traffic to reduce bandwidth consumption.
- [x] **Data Export:** Export logs and consumption reports.

## Ideas Parking Lot (Future Enhancements)

- Advanced AI-driven personalized saving strategies.
- Automated carrier plan detection and balance parsing.
- Family quota sharing and management dashboard.
